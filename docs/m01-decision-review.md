# M-01 decision review register

Updated: 2026-08-24

This file collects consequential `M-01` decisions for later owner review. They were implemented and independently verified on 2026-08-24; changing a decision later may require migration or rework.

| ID | Status | Decision | Basis | Rejected alternatives | Residual uncertainty |
|---|---|---|---|---|---|
| M01-D01 | Accepted for implementation | Use one UTF-8 JSON request and response per Unix stream connection, each terminated by LF; the server processes the first record, discards later bytes, responds, and closes without waiting for client EOF. | Architect consensus: explicit framing and bounded connection state suit health/status traffic. | Persistent NDJSON; EOF-delimited request; binary length prefix; nondeterministic post-LF rejection. | None material. |
| M01-D02 | Accepted for implementation | Protocol v1 uses strict envelopes, canonical lowercase UUID request/instance IDs, stable error codes, rejected unknown/duplicate fields, and shared byte fixtures. | Cross-language determinism; avoids repeating the spike's self-comparison defect. | Permissive decoding; numeric IDs; language-specific fixtures. | Duplicate-key validation requires deliberate parsers in both languages. |
| M01-D03 | Accepted for implementation | Frames are at most 16,384 bytes including LF; phase deadlines are one second; at most eight connections are handled concurrently; the ninth connection closes without a response. | Bounded resources with ample capacity for scaffold messages and deterministic overload behavior. | Default scanner limits; unlimited goroutines; configuration knobs; best-effort busy responses. | Test policies may inject longer deadlines on loaded systems without changing production defaults. |
| M01-D04 | Accepted for implementation | Swift uses verified `/private/tmp` and atomically creates an owner-only generation directory. Cleanup retains the first observed socket identity and never replaces it; identity drift is a security failure and observable mismatches remain untouched. Runtime and supervisor validate recorded identities immediately before pathname unlink. | Unique `0700` generation directories and identity guards cover other users, crashes, stale paths, and accidental substitution. macOS has no atomic inode-conditional pathname unlink. | Overwriting identity; blind or recursive cleanup; claiming `lstat` plus `unlink` is atomic; advisory locks as an adversarial control. | `M-01` trusts same-effective-UID processes and accepts their residual check/unlink race. Packaging must revisit App Sandbox or another isolation boundary. |
| M01-D05 | Accepted for implementation | Both sides must verify effective peer ownership before protocol bytes; inability to obtain credentials is fatal. Directory and socket ownership/modes are also mandatory. | Apple documents effective peer credentials for connected Unix stream peers; the installed SDK exposes the required Darwin APIs. Go uses a local standard-library syscall wrapper, keeping the root module dependency-free. | File modes alone; optional peer checks; unauthenticated endpoint discovery. | This is peer identity, not application authentication. |
| M01-D06 | Accepted for implementation | Swift passes an injected socket path and per-generation UUID instance ID. Ready requires a matching health response, not socket existence or process survival. | Attributes readiness to the launched process without secret storage. | PID matching; environment token; socket-exists readiness. | Instance ID is an attribution nonce, not a credential. |
| M01-D07 | Accepted for implementation | Supervision allows one restart after 500 ms per app launch. Shutdown sends SIGTERM, waits two seconds, sends SIGKILL if needed, then waits one second. Stdout/stderr are drained concurrently into separate 64 KiB tails. | Deterministic tests; prevents restart storms and pipe deadlock. | Unlimited/exponential retries; IPC shutdown command; unbounded or merged output. | Integration tests pass; packaging and sandbox behavior remain deferred. |
| M01-D08 | Accepted for implementation | `M-01` creates only exercised runtime/IPC/command boundaries and shared protocol artifacts. No action, notification, D200X, HID, or TOML implementation package is created. | Independent review found speculative packages contradicted scaffold exclusions. | Mirroring the future domain tree; copying spike code. | Consumer-owned config/device ports may be added only if an exercised fake requires them. |
| M01-D09 | Accepted for implementation | Go language baseline is 1.26; local verification uses Go 1.26.4. Swift verification uses Swift 6.3.3 and Xcode 26.6. | Installed toolchain facts recorded on 2026-08-24. | Claiming an unrun Go 1.27 gate. | Go 1.27 verification is optional and must be reported as not run unless an explicit toolchain is obtained. |
| M01-D10 | Implemented and verified | Xcode builds and atomically embeds the required Go runtime as `Contents/MacOS/hidhogg-runtime`; the app resolves only that bundle auxiliary executable and never searches `PATH` or `/usr/local/bin`. | `Contents/MacOS/hidhogg` collides with the Swift `Hidhogg` executable on default case-insensitive APFS. Architect consensus selected the distinct executable name over premature XPC or helper-service structure. | Case-only name distinction; shell `PATH`; `/usr/local/bin`; XPCServices; `Contents/Helpers` before packaging design. | Distribution signing of the shell-built nested executable is deferred and must be verified before release. |
| M01-D11 | Implemented and verified | An application delegate eagerly starts the runtime at process launch and uses AppKit's terminate-later handshake for asynchronous cleanup. Hosted tests use a dedicated `Test` build configuration that compiles out only automatic app-owned startup; explicit live integration remains active. | `MenuBarExtra` content is lazy, and hosted XCTest teardown does not perform normal app termination. Architect consensus rejected process/XCTest heuristics and ineffective scheme-argument propagation. | Menu-content `.task`; `scenePhase`; environment inspection; XCTest class/process heuristics; accepting test-created orphans. | A manually launched Test-config app intentionally does not auto-start; Test artifacts are not release candidates. |
| M01-D12 | Implemented and verified | The Xcode build phase discovers Go in standard Apple Silicon Homebrew, official installer, and Intel Homebrew locations before falling back to its supplied `PATH`; absence produces actionable remediation. | GUI-launched Xcode did not inherit the interactive shell path containing `/opt/homebrew/bin/go`. A restricted-path build reproduced the boundary and verified the correction. | Requiring shell startup files; one developer-specific path; copying a prebuilt untracked binary. | Nonstandard Go installations must expose `go` through the build phase `PATH` or use a supported location. |

## Primary sources

- Apple, [`getpeereid(3)`](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/getpeereid.3.html): effective credentials for connected Unix-domain stream peers.
- Apple, [`Process`](https://developer.apple.com/documentation/foundation/process): child launch, monitoring, standard streams, termination, and sandbox inheritance.
- Apple, [`Pipe`](https://developer.apple.com/documentation/foundation/pipe): bounded operating-system pipes require active draining to avoid blocking writers.
- Apple, [`MenuBarExtra`](https://developer.apple.com/documentation/swiftui/menubarextra): persistent SwiftUI menu-bar scene.
- Go, [release history](https://go.dev/doc/devel/release): upstream release and support history.

## Local verification facts

- `/usr/include/sys/un.h` in the Xcode 26.6 macOS SDK declares `sun_path[104]`; the complete encoded path must fit with its terminator.
- Swift 6.3.3 imports Darwin `getpeereid` and reports `sockaddr_un` size 106 with a 104-byte path field.
- The Go implementation uses `syscall.SYS_GETSOCKOPT` with Darwin `SOL_LOCAL` and `LOCAL_PEERCRED`; the root module has no third-party dependencies.
