# NX-M1 implementation contract

2026-10-19. Owner approved maximum practical implementation of NX-02–04 with supervised sub-agents. Offline fixtures/builds/package verification are authorised; agents do not execute hardware helpers, inspect private configuration or post input to owner applications. Physical acceptance remains an owner checklist.

## Decisions and alternatives

15. **TOML:** select `mattt/swift-toml` exact 2.0.0, module TOML, Codable decode/encode and bounded decoder input. The reviewed release manifest contains Swift and a toml++ C wrapper, no package plugins or transitive Swift packages. Alternatives: older TOMLKit wrapper, decoder-only library plus manual writer, JSON. Native Codable and round-trip tests make the selected dependency the smaller implementation. Pin resolution and retain MIT notices. Sources: https://github.com/mattt/swift-toml and its 2.0.0 Package.swift, reviewed 2026-10-19. UI saves rewrite formatting/comments; no lossless editing promise.
16. **Model:** schema_version1, logical device profile `logitech.mx-master-3s`, required Back/Forward defaults, sparse per-bundle-identifier overrides. Missing override inherits; explicit disabled suppresses action while bindings are enabled. Defaults start disabled, not arbitrary key actions. Enabling diversion suppresses native button behaviour; UI must say so. No implicit firmware/onboard persistence.
17. **Keys:** physical macOS virtual key code with Command/Option/Control/Shift enum values. Labels use current keyboard layout, not US lookup. No arbitrary text or shell actions in first slice. One balanced down/up per fresh button press; no held repeats or delayed replay.
18. **Configuration:** config.toml under absolute XDG_CONFIG_HOME/hidhogg or home/.config/hidhogg. Atomic validated saves and last-read byte revision; detect external changes before saving. This detects ordinary edits, not a universal compare-and-swap against malicious concurrent writers. Manual reload retains last good document on failure. Whole-document draft survives navigation; reload with dirty draft requires deliberate discard or cancel. No watcher, automatic migration or silent overwrite of invalid data. Tests use temporary injected paths.
19. **Binding activation:** disabled on each launch; discovery reads only after explicit Connect. Owner confirms this is the intended MX Master 3S/Bolt candidate and no competing mouse software before enabling. Only advertised uniquely eligible Back/Forward controls can be diverted. Fresh runtime feature index, slot and baseline; no serial/unique device identifiers. Ambiguous receivers/devices fail closed. Single session owns both controls; no runtime daemon.
20. **Lifecycle:** bounded serial HID++ requests; input delivery generation-fenced and release-armed. Disabling immediately prevents action posting, then conditionally restores only states attributable to this session and separately reads restoration. Uncertain restoration stays visible and blocks rearm. Disconnect/sleep stops delivery and does not auto-reenable. Orderly quit awaits cleanup; abrupt crash recovery is not claimed.
21. **Transport:** IOKit non-seizing HID report path based on bounded LogiBridge source evidence. Forward CID/task mapping remains a candidate requiring live advertisement and owner verification. No CoreHID compatibility claim. No borrowed frozen diagnostic executable, no hardware test runs in development. Discovery timeouts are visible instead of hidden retry loops.
22. **UI:** native sidebar/Form/Picker/Button/sheets, explicit Save and Reload, native toolbar history bounded to64 deliberate routes. Store drafts above views. Connection status dot next to status text, separate from saved/permission/applied status. Custom mouse drawing only for control selection; numeric fallback key display acceptable for unmapped layout keys. No simulated connected state in production.
23. **Press admission:** a generation number alone cannot prevent a dequeued event from executing after native disconnect. A synchronous lock-protected admission gate checks the current session and a maximum 250ms event age, then completes one balanced shortcut pair before releasing the lock. Native terminal events invalidate admission immediately. Alternative: asynchronous checks before posting, which leave an interleaving window. No await or actor call occurs inside the posting closure.
24. **Save/reload transitions:** freeze draft mutation before asynchronous work begins. A save updates the submitted saved baseline; reload replaces the draft only after validation and deliberate discard confirmation where required. Missing configuration requires an intentional initial Save; load failures cannot be overwritten from the editor. Save/reload stop active bindings and require explicit reconnect/enable. Alternatives: silently overwrite a bad file or automatically re-divert hardware after saving; rejected to preserve owner control.
25. **Queued intent:** main-actor intent revisions invalidate queued Connect/Enable on Stop, sleep, quit, permission loss or recording. Controller cancellation separately guards operations already underway. Alternatives: rely on Task scheduling order or only disable posting; neither prevents a stale command starting a later session.
26. **Selective device opening:** retain explicit opening of the selected HID endpoint. Review of [Apple's IOHIDManager implementation](https://github.com/apple-oss-distributions/IOKitUser/blob/main/hid.subproj/IOHIDManager.c) found matching callbacks independent of manager-wide open; adding it would open matched devices unnecessarily. IndependentDevices scheduling isolation is a possible follow-up without a demonstrated defect; no installed-OS callback acceptance is claimed. Empty-runloop ownership regression did not reproduce a Thread cycle; finished worker references are nevertheless explicitly cleared.

## Modules

`HidhoggDomain` typed values; `HidhoggConfiguration` parser/store/path resolver; `LogitechBolt` transport/protocol/controller; `MacOSActions` current-layout labels/permission/shortcut posting; `HidhoggApp` main-actor app model, draft/navigation and native views. Actor/queue ownership at OS boundaries; no idle UI polling.

## Verification boundaries

Focused domain/configuration/protocol/session/navigation tests, no private environment or config reads. Synthetic runtime tests and package builds do not validate Forward hardware, Options+ contention, real key layout delivery, reconnect or crash recovery. Final manual checklist must say which remain. Keep dist path and existing certificate identity; preserve prior signed app until verified replacement is ready.
